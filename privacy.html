Privacy policy — shag-mail

Last updated: 28 September 2026

shag-mail is a personal tool that its owner runs on their own computer to read their own mailbox.

Data accessed

Only with the account owner's consent, shag-mail uses the Gmail API scope gmail.readonly to read message metadata, message content and attachments.

How data is used and stored

  • Data is processed only on the owner's own computer, for the owner's own work.
  • The OAuth token is stored only on that computer. It is never sent to third parties.
  • No data is sold, shared, or used for advertising. No data is sent to any server operated by the author.
  • shag-mail's use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions.

Contact

Questions about this policy: open an issue at github.com/therugn/shag-mail.
